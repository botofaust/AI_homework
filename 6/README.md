# Проверка файлового обмена через Vanessa Automation

Проверка выполнена 18.11.2026 на Vanessa Automation Single 1.2.043.47 и платформе 1С 8.3.27.1936. Использованы существующие базы `var/ib` и `var/ib_integ`, отдельный тестовый счет и сценарии взаимодействия с формой обмена.

Успешно выполнены:

- Выбор счета и выгрузка JSON кнопкой «Сохранить в файл»; подтверждено создание непустого файла.
- Предварительный просмотр файла и создание счета в принимающей базе без проведения.
- Сверка UUID, номера, даты, всех передаваемых реквизитов шапки и строк товаров с содержимым файла.

Vanessa обнаружила ошибку повторной загрузки при изменении года: ожидалось сообщение «Счет обновлён без проведения.», получено «При записи изменился номер или дата счета из файла. Загрузка отменена.». Запись была отменена защитной проверкой расширения. Этот упавший сценарий оставлен как пример найденной ошибки; исправления в прикладной код не вносились.

При первом запуске принимающей базы стартовая вкладка БСП «Информация» мешала сценарию. Подготовка сценария скорректирована: ожидание старта и закрытие вкладок перед открытием формы обмена.

Подготовлены, но не запущены отдельные сценарии отсутствующей ссылки, конфликта номера, неполного файла, отмены выбора файла и запрета обновления проведенного счета.

Артефакты в этой папке:

- `screenshots/` — скриншоты интерфейса и результатов.
- `reports/source-export/junit.xml` — успешная проверка выгрузки.
- `reports/target-positive/junit.xml` — создание счета и упавшая повторная загрузка.
- `logs/` — журналы запусков.
- `diagnostics/` — материалы предыдущих попыток и диагностики.
- `scenarios/`, `settings/`, `data/` — сценарии, параметры запуска и файлы обмена.
