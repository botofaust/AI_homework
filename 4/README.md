* Использование MCP

** Отчет по результатам

1. Был выбран onec, который сейчас установлен глобально, довольно ощутимо экономит токены, так как метаданные не ищутся поиском по xml файлам выгрузки, а берутся напрясую из базы. Так же протестированы инструменты запросов и выполнения кода в базе, работает. Вывод: использовать всегда при наличии базы данных.

2. Был установлен b24-dev-mcp предоставляющий документацию о методах API Битрикс24. Работает :) Столкнулся с проблемой, mcp давал неверную информацию о методе tasks.elapsedtime.add, утверждая, что нет у него параметра CREATED_DATE, послал агента в интернет, так как знал точные параметры метода. Вывод: не верить новому mcp слепо, нужна дополнительная проверка.

3. Установлен MCP bls_language_server локально в проект. Работает. Дает ощутимое улучшение в качестве и скорости написания кода, прекращаются бесконечные итерации "а я неправильно транзакцию построил".
