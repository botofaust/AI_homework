# Шаблон среды разработки 1С

Копируемый комплект для Windows PowerShell 5.1 и PowerShell 7. Содержит скрипты 1С, навыки Superpowers, BSL Language Server 1.0.7 и Vanessa Automation Single 1.2.043.47. Конфигурация, расширения, Java, платформа 1С и информационная база поставляются отдельно.

## Начало работы

1. Распакуйте ZIP и скопируйте папку `project-template` в нужное место. Переименуйте её в имя нового проекта. Переносите папку целиком, включая `.agents`.
2. Установите Java (ориентир — JDK 25, как в исходной среде) и версию платформы 1С, подходящую вашей конфигурации. Установщик их не скачивает и не проверяет их версии запуском.
3. Откройте PowerShell в новой папке. При блокировке скриптов разрешите запуск только для текущего процесса:

   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\setup.ps1
   ```

   Java ищется в `JAVA_HOME`, затем в `PATH`. Платформа — по `ONEC_EXE`, затем в стандартных каталогах установки (самая новая из найденных). Если требуется конкретная версия, задайте пути явно:

   ```powershell
   .\setup.ps1 -JavaExecutable 'C:\Program Files\Java\jdk-25\bin\java.exe' -OneCExecutable 'C:\Program Files\1cv8\8.3.27.1936\bin\1cv8.exe'
   ```

   Пути в примере замените своими. Версия `8.3.27.1936` не является требованием шаблона.
4. Откройте новую сессию Codex в этом проекте. Для загрузки проектной настройки MCP проект должен быть доверенным. Выполните ручную проверку подключения BSL MCP. Остальные MCP подключаются отдельно.

`setup.ps1` создаёт `.codex/config.toml` для MCP и `.codex/onec-path.txt` для скриптов 1С. После перемещения папки или смены компьютера повторите настройку. При необходимости обновите параметры путей. Скрипт обновляет только свои файлы с меткой генерации и отказывается перезаписывать чужие. Если вы добавили собственные настройки в сгенерированный файл, сохраните их перед повторным запуском и объедините вручную. Глобальные настройки и переменные окружения пользователя не меняются.

При отсутствии зависимости или файлов комплекта настройка прекращается с объяснением. Установите зависимость либо восстановите полный комплект и повторите команду. Скрипт не запускает Java, MCP, 1С или Vanessa и не создаёт ИБ.

## Добавление своей конфигурации

Заполните `src/cf` XML-выгрузкой своей основной конфигурации, а `src/cfe/<ИмяРасширения>` — исходниками расширений. Либо поместите свой `.dt` в `var/templates` для последующего восстановления. Рабочая база — `var/ib`.

До использования команд уточните версию платформы, режим совместимости, формат XML и пользователя ИБ. Запишите сведения о своём проекте в `AGENTS.md`. Не используйте более новую платформу автоматически, если исходники требуют конкретную версию.

Команды ниже выполняйте осознанно: загрузка, восстановление и обновление меняют ИБ. Установка шаблона их не запускает. Примеры альтернативны: не нужно выполнять все команды подряд.

| Команда | Назначение |
|---|---|
| `./tools/new-infobase.ps1` | Создать пустую файловую ИБ |
| `./tools/restore-infobase.ps1 -TemplatePath 'var/templates/MyBase.dt'` | Восстановить свой шаблон; при отсутствии ИБ создать её |
| `./tools/dump-config.ps1` | Выгрузить основную конфигурацию в `src/cf` |
| `./tools/load-config.ps1` | Загрузить основную конфигурацию из `src/cf` |
| `./tools/update-db.ps1` | Обновить конфигурацию БД |
| `./tools/load-extension.ps1 -ExtensionName 'МоеРасширение' -Create` | Первая загрузка расширения |
| `./tools/load-extension.ps1 -ExtensionName 'МоеРасширение'` | Обновить исходники расширения в ИБ |
| `./tools/dump-extension.ps1 -ExtensionName 'МоеРасширение'` | Выгрузить исходники расширения |
| `./tools/update-extension-db.ps1 -ExtensionName 'МоеРасширение'` | Применить расширение к структуре БД |
| `./tools/pack-extension.ps1 -ExtensionName 'МоеРасширение'` | Собрать файл поставки в `releases` |
| `./tools/backup-infobase.ps1` | Создать резервную копию только по явной просьбе |
| `./tools/check-config.ps1` | Проверить конфигурацию; запускает только пользователь |
| `./tools/check-extension.ps1 -ExtensionName 'МоеРасширение'` | Проверить расширение; запускает только пользователь |

Важная особенность перенесённого скрипта: `load-extension.ps1 -Create` передаёт платформе каталог, содержащий выбранное расширение, с флагом `-AllExtensions`. Поэтому первая загрузка затрагивает все расширения в этом каталоге, а не только указанное имя. Используйте её, когда в `src/cfe` находится только создаваемое расширение либо когда намерены загрузить все соседние расширения. Без `-Create` загрузка адресована указанному расширению.

Для существующей базы не требуется ни создание, ни восстановление. Передайте путь через `-InfoBasePath` либо `ONEC_INFOBASE_PATH`.

Общие параметры подключения: `-OneCExecutable`, `-InfoBasePath`, `-UserName`, `-Password`; соответствующие переменные: `ONEC_EXE`, `ONEC_INFOBASE_PATH`, `ONEC_USER`, `ONEC_PASSWORD`. Исключение — создание пустой ИБ: у него только параметры платформы и пути базы.

Платформа выбирается в порядке: явный параметр → `ONEC_EXE` → сохранённый setup путь → поиск установленной платформы. Если сохранённый путь больше не существует, повторите setup или передайте новый явно. По умолчанию используется `Администратор` с пустым паролем; для своей ИБ укажите подходящие данные. Пароли в файлах шаблона не храните.

## Локальные инструменты

- BSL MCP: `var/tools/bsl-language-server/bsl-language-server-1.0.7-exec.jar`, транспорт stdio, heap 2 ГБ, таймауты 120 секунд. Процесс запускает клиент Codex. Навигация зависит от передачи клиентом рабочих каталогов MCP roots. Ассистент не вызывает `analyze_file`.
- Vanessa: `var/tools/vanessa-automation/vanessa-automation-single.epf`. Открывается пользователем как внешняя обработка в своей ИБ, при необходимости в режиме менеджера тестирования. Сценарии и дополнительное расширение VAExtension не включены.
- Superpowers: `.agents/skills`, источник https://github.com/obra/superpowers, ревизия `22f0b463e7a5e579904dd6211a520321035526f7`; действуют ограничения из `AGENTS.md`.

Комплект использует существующие бинарные файлы исходного проекта без скачивания. Сведения об источниках: BSL Language Server — https://github.com/1c-syntax/bsl-language-server/releases/tag/v1.0.7; Vanessa Automation — https://github.com/Pr-Mex/vanessa-automation/releases/tag/1.2.043.47.

Тестирование и проверки конфигурации выполняет только пользователь. Автоматические тесты и сценарии в шаблоне отсутствуют.
