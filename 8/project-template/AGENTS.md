# AGENTS.md

## Проект

Проект 1С. Источник истины — XML-выгрузка в `src/cf` и `src/cfe`. `var/` содержит только локальную среду выполнения.

Конфигурация и информационная база в шаблон не входят. До работы с ними уточнить версию платформы, режим совместимости и формат XML по данным конкретного проекта. Не считать наличие каталогов подтверждением существования ИБ или исходников.

## Правила

- Тестирование проводит только пользователь. Ассистент не создаёт тесты и автоматические тестовые сценарии и не запускает тесты или проверки конфигурации. Через BSL MCP не вызывать `analyze_file`.
- Реализация максимально простая: только необходимое для текущей задачи, без лишних абстракций, зависимостей и функциональности на будущее.
- Git не используется. Не выполнять команды Git, не создавать коммиты, ветки и рабочие деревья.
- Не применять массовое форматирование к XML-выгрузке.
- Не создавать отдельную или копию ИБ для проверок без явной просьбы. Локальная рабочая ИБ — `var/ib`.
- Не делать резервные копии перед применением изменений, включая обновление конфигурации БД и реструктуризацию. Резервная копия — только по явной просьбе пользователя.
- После изменений в `src/cf` или `src/cfe` сообщать, что они готовы к ручному тестированию; проверку конфигурации пользователь запускает самостоятельно.
- Не изменять поставляемые объекты без необходимости. Прикладной код держать в расширениях, пока не определены собственная подсистема и префикс проекта.
- Настройка инструментов не даёт разрешения создавать, восстанавливать или изменять ИБ.

## Инструменты

Команды PowerShell находятся в `tools/`; запускать их из корня проекта. У скриптов расширений обязательно указывать `-ExtensionName`. Назначение и параметры — в `README.md` и самих скриптах.

По умолчанию скрипты используют пользователя `Администратор` с пустым паролем. Это значение скриптов, а не утверждение о пользователях конкретной ИБ. Переопределение: `-UserName`, `-Password`, `ONEC_USER`, `ONEC_PASSWORD`. Не сохранять пароли в шаблоне.

Путь к 1С: `-OneCExecutable`, затем `ONEC_EXE`, затем настройка `setup.ps1`, затем поиск установленной платформы. Версия должна соответствовать исходникам проекта; не переключаться на другую без необходимости.
