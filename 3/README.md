* Создание HTTP-сервиса чтения и установки цен

** Окружение

Используемый стек: VSCode, Codex plugin, GPT-5.6 Sol medium, MCP onec, набор скилов Superpowers в проекте.

** Проблемы и решения

1. Зная, что Superpowers заставит тестировать каждое изменение кода, явно запретил использовать автотесты и git в AGENTS.md. Изменения положительно отразились на стоимости и скорости, субъективно - на порядки. Расширение всё равно проверяется при загрузке в базу и исправляется.

2. Забыл, что скилл для создания расширения подготовлен в OpenCode и Codex его не использовал, а это бы еще сократило расходы на итерации, так как с первого раза почему-то не выходит создать скелет расширения ни у одного из агентов.
