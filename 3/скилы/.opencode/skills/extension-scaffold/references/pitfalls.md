# Подводные камни каркаса расширения

## Скопированные UUID

Каждый новый объект метаданных получает собственный UUID. Нельзя копировать UUID из `src/cfe/УстановкаЦен`, `src/cfe/АдресноеХранение` или любого другого расширения: два объекта с одинаковым UUID конфликтуют, а платформа может незаметно связать новый объект с чужим. Для конфигурации, языка, подсистемы и всех семи `xr:ObjectId` используйте `[guid]::NewGuid()`.

## Отсутствует внутренняя информация

`Configuration.xml` расширения должен содержать ровно семь элементов `xr:ContainedObject` с фиксированными `ClassId` и свежими `ObjectId`. Без них загрузка падает с сообщением «Отсутствует внутренняя информация». Список `ClassId` и их порядок нельзя менять.

## Нет `ObjectBelonging=Adopted`

У конфигурации расширения и у заимствованного языка в `Properties` должно быть `<ObjectBelonging>Adopted</ObjectBelonging>`. Без этого платформа отказывается загружать файл с сообщением о недопустимом изменении принадлежности объекта.

## Режим совместимости выше основной конфигурации

`ConfigurationExtensionCompatibilityMode` должен быть `Version8_3_14` — не выше режима совместимости основной конфигурации. XML с более новым режимом может загрузиться, но `check-extension.ps1` отклонит расширение на шаге `CheckCanApplyConfigurationExtensions`. Не заменяйте значение на режим текущей платформы.

## Неверный UUID языка

`Language.ExtendedConfigurationObject` в `src/cfe/<Имя>/Languages/Русский.xml` должен совпадать с атрибутом `uuid` элемента `<Language>` в `src/cf/Languages/Русский.xml`. Это значение читается из основной конфигурации при создании каркаса; его нельзя придумывать или брать из другого расширения. UUID самого файла языка расширения при этом остаётся свежим.

## `ChildObjects` не совпадает с файлами

В `Configuration.xml` в `ChildObjects` перечисляются только те объекты, для которых есть файлы: `Language` и `Subsystem`. Лишняя запись без файла или файл, не указанный в `ChildObjects`, приводит к ошибке загрузки. При добавлении новых объектов в будущем обновляйте оба места одновременно.

## `-Create` загружает все расширения

`./tools/load-extension.ps1 -ExtensionName <Имя> -Create` передаёт в 1С родительский каталог `src/cfe` с ключом `-AllExtensions`, поэтому загрузка затрагивает и соседние расширения. Если соседнее расширение сломано, создание нового тоже упадёт. `-Create` нужен только для первого появления расширения в ИБ; для существующего расширения используйте команду без этого ключа.

## Выгрузка после загрузки — эталон

После `load-extension.ps1` платформа убирает значения по умолчанию и нормализует XML. Расхождение рукописного каркаса и результата `dump-extension.ps1` нормально: эталоном считается выгрузка. Не пытайтесь вручную подгонять файлы под шаблон после выгрузки.

## Реструктуризация ИБ и открытый клиент

`update-extension-db.ps1` меняет структуру информационной базы и в создание каркаса не входит. Запускайте её только после `backup-infobase.ps1` и с разрешения пользователя. Открытый клиент 1С блокирует ИБ, поэтому перед командами `tools/*.ps1` закройте сеансы.

## Кодировка

Файлы выгрузки — UTF-8. В Windows PowerShell 5.1 `Get-Content` без `-Encoding UTF8` читает кириллицу в системной кодировке и портит XML. При чтении шаблонов и `src/cf/Languages/Русский.xml` всегда указывайте `-Encoding UTF8`, а записывайте файлы через `[System.IO.File]::WriteAllText` с `UTF8Encoding($false)`.
