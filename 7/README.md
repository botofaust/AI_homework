* Описание выполненных работ

Технически тесты выполнены в виде отдельного расширения. Созданы **пять unit-тестов**, которые проверяют обработку ошибочных входных данных:

1. **Некорректный JSON.** Передается незавершенный JSON. Проверяется, что разбор возвращает ошибку чтения, данные счета отсутствуют, а исходный текст сохраняется для просмотра.
2. **Неизвестный формат.** Передается `format = order` вместо `invoice`. Ожидается сообщение о неподдерживаемом формате.
3. **Неподдерживаемая версия.** Передается `version = 2` вместо поддерживаемой версии `1`. Проверяется отказ с соответствующим сообщением.
4. **Отсутствие обязательного поля.** Из шапки счета исключается поле `Комментарий`. Проверяется, что неполный файл отклоняется, даже если отсутствующий реквизит может содержать пустое значение.
5. **Лишнее поле.** В корень JSON добавляется неизвестное поле `extra`. Проверяется соблюдение контракта: файл с незнакомыми полями не принимается.

Также созданы **два интеграционных теста**, работающих с реальной записью документов:

1. **Создание счета из JSON.** На основе существующего корректного демосчета подготавливаются данные с новым UUID, свободным номером и двумя строками товаров. Проверяется создание документа без проведения, сохранение номера, даты, реквизитов и сумм. Затем счет выгружается обратно в JSON и сравнивается с переданными данными.
2. **Обновление счета и повторная загрузка.** Сначала создается счет с двумя строками. Затем для того же UUID меняются комментарий, сумма оплаты и данные товаров, а две строки заменяются одной. Проверяется, что обновляется прежний документ, старая строка удаляется, суммы сохраняются без пересчета. Повторная загрузка того же файла должна сохранить ссылку и данные без создания дубликата.

Интеграционные тесты выполняются в транзакции с откатом изменений. Исходный демосчет используется только для чтения. Обмен между двумя отдельными базами и работа формы этими сценариями не покрываются.

**Назначение тестов** — выявлять нарушения формата обмена, потерю или искажение данных и ошибки повторной загрузки после доработок.
