**Vanessa Automation** — инструмент автоматизации проверки интерфейса 1С. Сценарии записываются в `.feature` на языке Gherkin: открыть форму, выбрать значение, нажать кнопку и проверить результат. Vanessa также снимает скриншоты и формирует отчёты.

В нашей работе менеджер тестирования запускал сценарий, а клиент тестирования выполнял действия в базе `AI_edu/var/ib`. После проверки из полученных скриншотов была собрана PDF-инструкция.

**Итоги проверки РКО:**

- Проверены создание, заполнение, запись и повторное открытие документа.
- Подтверждено автоматическое заполнение поля «Выдать» после выбора получателя.
- После открытия сверены номер, получатель, операция, касса, сумма и комментарий.
- Финальный результат: **1 успешный тест, 0 ошибок**, восемь скриншотов.
- РКО № `00000000005` сохранён без проведения. Подготовлена инструкция на шести страницах.

**Выводы.** Сценарий необходимо адаптировать к конкретной конфигурации. Например, поле «Касса» оказалось составным: перед выбором кассы требуется выбрать её тип. Для устойчивости удобно обращаться к элементам по внутренним именам, проверять открытие нужного окна и сверять данные после повторного открытия документа. Успех следует оценивать по отчёту и проверкам значений: одного запуска без аварии недостаточно.

**Пример из выполненного сценария** — после подключения клиента и открытия нового РКО:

```gherkin
И из выпадающего списка с именем 'ФизическоеЛицо' я выбираю по строке 'Николаева Светлана Яковлевна'
Тогда элемент формы с именем 'Выдать' стал равен 'Николаевой Светлане Яковлевне'

И в поле с именем 'Сумма' я ввожу текст '1234,56'
Тогда элемент формы с именем 'Сумма' стал равен '1 234,56'
```
